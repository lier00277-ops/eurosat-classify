## 一、项目说明

**项目名称**：EuroSAT 遥感地物分类 —— 手写 ResNet 从零训练

**项目简介**：用 PyTorch 从零写了 ResNet18，对 EuroSAT 卫星影像做 10 类地物分类。项目包括数据下载与清洗、分层划分、统计分析、训练评估、错误分析、Grad-CAM，以及一个 FastAPI 推理服务。

**技术路线**

- 数据：EuroSAT RGB，27,000 张 64×64 图像 / 10 类；Pandas 做统计清洗，Matplotlib 做可视化
- 模型：手写 BasicBlock + ResNet18（11.18M 参数），针对 64×64 小图改用 3×3 stride1 主干
- 训练：PyTorch + OneCycleLR，Kaggle 免费 GPU（T4）训练 30 epoch
- 评估：准确率、每类 P/R/F1、混淆矩阵、高置信度错分样本
- 扩展：Grad-CAM 可解释性、迁移学习对照实验、FastAPI 推理服务

**主要结果**

| 指标 | 结果 |
|---|---|
| 测试集准确率 | **97.61%** |
| 最佳验证准确率 | 97.30% |
| 训练时长 | 约 9.4 分钟（T4 / 30 epoch） |
| 最弱类别 | Permanent Crop，F1 = 0.953 |

**主要结论**：错误主要来自视觉相似（植被类之间、建成区之间），而不是样本不均衡；Grad-CAM 可视化进一步验证了这一点。

**运行方式**

```powershell
python -m src.data.download    # 数据下载与处理
python -m src.train            # 训练（CPU 可跑）
python -m src.evaluate         # 测试集评估
.\scripts\run_serve.ps1        # 推理服务：http://127.0.0.1:8001
```
